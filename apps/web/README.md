# 共壤 R0 本地工作台

Vue 3 + TypeScript + Vite 的单社区中文工作台，实际调用同源 `/api/v1` 后端。所有本轮议题、资料和任务均为合成开发样本。

```sh
npm ci
npm run dev
```

开发服务器默认仅监听 `127.0.0.1:5173`，`/api` 代理到 `127.0.0.1:8000`。后端需允许对应开发页面的 Origin；代理保持同源调用，不依赖 CORS。单服务器部署使用构建产物 `dist`，由 FastAPI 提供同源静态资源。

```sh
npm run typecheck
npm test
npm run build
```

## 已完成的 R0 路径

- 显式账号登录、一次性邀请注册；管理员建立邀请和冻结账号。
- 六入口首页；本人收到的邀请可打开完整条款并回应。
- 关键词查询、资料原文与来源。
- 私人原话保存/编辑、绑定版本的本人准确确认、明确受众的分享预览、撤回分享。
- 议题范围、参与者、已共享观点、备选方案、五类立场；仅授权主持人或管理员发起议题。
- 发起人邀请任务，受邀者本人接受、拒绝或协商条件。
- 个人分享权限、会话记录及本人审计。

## 会话与数据处理

客户端不使用 localStorage、sessionStorage 或 IndexedDB 保存私人内容或身份令牌。会话依赖 HttpOnly cookie，CSRF 令牌只保留在内存。关键确认、分享、立场和任务回应携带幂等键；网络未收到确认时，相同操作重试会复用键。

刷新页面或新标签页必须显式登录，不会凭既有 cookie 自动恢复前一位成员的私人页面。退出立即清除页面内存，再向服务器请求注销；网络失败会明确显示服务器尚未确认撤销。闲置 5 分钟自动执行退出；最近 60 秒有人交互时，最多每 45 秒进行一次会话续期，避免成员持续编辑时误判闲置。客户端和服务器均需落实闲置过期。

原话编辑会使新版未经确认；确认准确不会增加分享范围。分享只发布本人确认的原话版本，不提供未实现的 AI 转述。撤回限制当前议题读取，无法撤销他人已经阅读或自行记录的内容。

## 当前限制

R0 不提供模型推理、理解核对、正式批准、公共屏、执行授权、复盘或共同记忆发布；页面展示后续阶段说明与人工路径，不使用模板假装 AI 输出。人工路径不会自动发送消息，真实受理人由社区另行配置。任务回应与方案立场不等于真实项目授权或社区决定。

# 共壤 R0.2 本地工作台

Vue 3 + TypeScript + Vite 的单社区中文工作台，实际调用同源 `/api/v1` 后端。所有本轮议题、资料和任务均为合成开发样本，不构成真实社区决定。

```sh
npm ci
npm run dev
```

开发服务器默认仅监听 `127.0.0.1:5173`，`/api` 代理到 `127.0.0.1:8000`。后端需允许对应页面的 Origin；代理保持同源调用，不依赖 CORS。单服务器部署使用构建产物 `dist`，由 FastAPI 提供同源静态资源。

```sh
npm run typecheck
npm test
npm run build
```

## 可用流程

- 显式账号登录、一次性邀请注册；管理员建立邀请和冻结账号。
- 六入口首页；本人收到的任务或理解核对请求可打开、核对和回应。
- 关键词查询、资料原文与来源。
- 私人原话保存/编辑、绑定源版本的本人准确确认。
- 最多两种私人候选：日常表达与本次讨论表达各一种；手写、修改、选择准确、只用原话或拒绝转述分别记录。
- 独立预览并分享原话或当前确认转述；只发布预览中的唯一正文，不夹带原话、私人语境或其他候选。可以撤回分享。
- 议题范围、参与者、已共享观点、方案与五类立场；仅授权主持人或管理员发起议题。
- 听者依据当前可见观点亲自复述；作者本人回应准确、需要修正或希望当面交流；正文仅双方可见。听懂不改变支持票和任务状态。
- 发起人邀请任务，受邀者本人接受、拒绝或协商条件。
- 个人分享权限、会话记录及本人审计。

## 可选模型建议

本地模型默认关闭；人工候选及理解核对可独立使用。模型状态来自服务器 `/ai/status`，启用配置不等于模型已经可用。

成员主动请求时，只发送当前原话和本人显式填写的三项语境。模型结果显示为未保存的私人建议；成员可打开编辑、主动保存，再选择和确认。客户端对建议请求最多等待约 65 秒，其余请求保持 20 秒；可以放弃等待或立即退出。取消后不接收结果，不冒称后端处理已经停止。

未改动的模型建议携带服务器短期来源证明。原话版本、候选类型、正文、背景、目标语境或用途改变时不沿用证明；修改既有候选始终作为本人手写或修改保存。来源证明过期时可明确选择去除证明、按本人手写内容保存。

## 会话与私人数据

不使用 localStorage、sessionStorage 或 IndexedDB 保存私人内容或身份令牌。会话需要 HttpOnly cookie 与页面内存中的 `X-CSRF-Token`；认证 GET 同样携带令牌。令牌仅由显式登录返回，不能凭残留 cookie 从 `/auth/me` 重新取得。

刷新页面或新标签页必须显式登录，不恢复前一位成员的私人页面。退出立即清除页面内存，再请求服务器注销；旧注销请求结束或 10 秒超时前禁用新登录，防止迟到的删除 cookie 响应影响新会话。网络失败如实提示服务器尚未确认撤销；残留 cookie 单独不能读取私人 API。

闲置 5 分钟自动退出；最近 60 秒有人交互时，最多每 45 秒续期，防止持续编辑误判闲置。关键确认、分享、选择、立场、理解核对与任务回应携带幂等键；网络未收到成功确认时，相同操作重试复用键。

原话修改使旧候选与选择失效。候选或选择变化停止旧分享。确认不增加分享范围；撤回限制当前议题读取，不能撤销他人已经阅读或自行记录的内容。

## 本轮边界

仍不提供正式批准、公共屏、真实执行授权、复盘或共同记忆发布；页面明确标注后续阶段并提供人工路径。人工路径不自动发送消息，真实受理人由社区配置。模型不读取历史私聊、不推断隐秘动机、不执行工具调用，也不代替作者确认、批准或承担责任。

# R0 本地模块化应用

日期：2026 年 10 月 5 日。状态：首轮开发基线。

采用 Vue 与 TypeScript 前端、FastAPI 与 SQLAlchemy 后端。身份、访问权限、表达确认、议题立场和任务回应由业务接口处理，AI 后续以可替换适配层接入。

R0 使用 SQLite 方便无 GPU、无 Docker 的开发环境完成整条人工协作流程。DATABASE_URL 为后续 PostgreSQL 迁移保留接口；仅有连接配置并不等于已经完成生产数据库、迁移及恢复验收。R1 再加入版本化迁移、PostgreSQL 专项测试和完整恢复演练。

当前不提供正式决定批准、公共屏、RAG、语音、共同记忆发布或真实资源执行。合成项目中的任务接受只说明演示参与者接受了演示条款，不能构成真实社区决定或执行授权。

采用服务端 Cookie 会话，正文与凭据不写入浏览器长期存储。确认、分享、立场和接受是独立动作；正式写入以服务端身份、版本、权限、业务前提和幂等检查为依据。

前端构建资源由本地应用提供，运行不使用 CDN。首次安装依赖需要联网；离线安装包及其全量恢复验收属于 R1 交付。代码仓库不存放真实成员资料、运行数据库、账号口令、恢复密钥和模型文件。

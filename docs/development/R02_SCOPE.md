# R0.2 合成数据开发范围

本轮沿用 R0 同一工作台与数据库，补齐跨语境表达和理解核对这一段实际流程。它是首期内部开发增量，不是完整 R1，不产生正式决定，也未开放真实社区资料。

| 增量 | 实际行为 | 交付边界 |
| --- | --- | --- |
| 会话读取证明 | 所有认证读写要求 Cookie 与页面内存证明；退出立即清内存 | Cookie 残留不再足以直接读取私人API；注销失败仍不冒称已撤销；未完成 MFA、恢复与现场公共终端验收 |
| 私人候选 | 每个原话版本最多日常／讨论两份；分别保存语境与版本 | 只本人可见，不根据身份猜动机，不读历史私聊；完整历史与导出后续实现 |
| 本人选择 | 确认具体候选、修改、仅保留原话或拒绝转述 | 候选确认不自动分享，原话核对与候选核对分开 |
| 唯一正文分享 | 选择原话或已确认转述，预览后显式分享 | 分享转述不夹带私人原话或背景；议题受众仍为动态成员，不提供期限或指定个人授权 |
| 修改及撤回 | 原话、确认候选或选择改变使当前分享失效 | 当前界面与后续读取停止展示，不能追回已经被人阅读的内容 |
| 理解核对 | 听者复述，由说话者核对准确／提出修正／当面交流 | 双方私有，不变化为立场、任务接受或正式批准；需修正后可另建新复述，尚无完整往返会话 |
| 可选本地模型 | 真实 loopback Ollama 适配器、私人建议预览、结构与来源校验 | 默认关闭，模型缺失时人工流程可用；测试替身验证不代表安装了真实权重或验证了中文质量 |

原数据库只增加 expression_candidates、expression_choices、expression_shares、understanding_requests 四张表。原有账号、原话和原话分享继续保留，不要求删除旧库重新 seed。生产迁移、备份恢复和删除传播仍是待交付项。

验收以 [VALIDATION_R02.md](VALIDATION_R02.md) 的实际记录为准。原产品书和上传实施方案的完整要求保留，参见 [实施方案对照](../product/IMPLEMENTATION_ALIGNMENT.md)。正式批准、公共屏、知识审核与RAG、行动核验、共同记忆多人授权和独立接管未因本轮完成而关闭。

# R0.4 双方私有资料纠错

在 R0.3 资料库上实现 F02 的纠错路径，对应 GR-14、GR-15、GR-04、GR-19 的部分增量。分支 `codex/r04-private-corrections`，以 R0.3 分支为基线；不合并 main，不部署生产。

成员从有权查阅的精确资料版本提出问题，预览版本和实际接收人，勾选分享后仅发给录入者。维护人文字说明不代表账号身份，服务器以资料 owner_id 选定接收人。录入者主动回应一次；如需修订，打开本人资料管理、手动另存完整新稿并重新送审。回应本身不修改资料，不代表问题已解决。

| 能力 | 本轮边界 |
| --- | --- |
| 提交 | 当前有效发布、精确版本和授权水位；不能给自己发；双方账号有效；不复制整篇原文 |
| 私有记录 | 请求和回应仅双方可读，账号管理员无通读权，不进入资料检索或模型上下文 |
| 关联原文 | 每次按当前权限核对同一版本；旧版被取代、撤下、到期或权限收紧时返回空来源 |
| 独立共享 | 原文不可查阅不自动撤回已明确分享的问题；页面发送前说明两种授权的差别 |
| 撤回 | 请求者可在回应前后撤回；接收方列表、计数、详情及旧请求重放停止读取；本人保留历史 |
| 状态 | 仅待回应、已回应、本人已撤回共享；不设自动解决、信任分或贡献排名 |
| 写入可靠性 | 服务端版本检查、幂等、原子审计；撤回与回应竞争不能复活共享 |

接口见 [API_CONTRACT_R04.md](API_CONTRACT_R04.md)。本轮不交付完整 F11 申诉、多人转派、持续聊天、回应方单独撤回、站外通知、完整删除导出、恢复撤权重放或真实模型质量。已被人看到或另存的内容不能由撤回操作追回。R1 与社区试点仍未验收。

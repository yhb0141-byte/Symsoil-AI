# R0 开发范围与验收

这是 R0 基线范围；当前增量见 [R02_SCOPE.md](R02_SCOPE.md)。本页保留原交付边界和历史缺口。

R0 是产品书中首个可运行开发版本。采用合成社区、人工流程和数据库，先验证产品的权限及确认规则。

| 能力 | R0 交付 | 后续工作 |
| --- | --- | --- |
| 工作台 | 中文首页、六入口、待回应、桌面及手机界面 | 真实社区配置及更广泛可及性测试 |
| 身份 | 本地登录、一次性注册邀请、会话退出、管理员冻结 | 多因素认证、恢复码、细化角色期限 |
| 资料 | 合成资料目录、关键词查询与原文 | 文件入库、授权检索、RAG 与模型评测 |
| 表达 | 私人原话、本人准确性确认、明确分享、撤回与版本冲突 | 本地模型转述、理解核对与共同词义 |
| 议题 | 有范围的议题、参与者、观点、选项和五类立场 | 正式批准规则、公共屏及程序核对 |
| 任务 | 独立邀请、本人接受、拒绝和提出条件 | 决定效力及资源条件、变更、核验、复盘 |
| 权限 | 原话访问、共享范围、账号冻结、本人审计 | 数据请求、导出、独立撤权日志与恢复 |
| 共同记忆 | 说明与人工记录入口，不生成已发布故事 | 多人授权、审核、撤下与索引同步 |
| 运行 | 本地启动、前端构建、基础测试 | 离线安装包、备份恢复、现场试用和接管 |

每项实际完成状态以测试结果和本轮发布说明为准，产品书的完整要求不会因 R0 的范围缩小而标为全部完成。

首轮测试重点：登录与 CSRF、私人草稿的对象权限、修改后重新确认、分享前置条件、撤回后的读取、缺席不算赞同、邀请只由本人回应、幂等重试、错误版本拒绝及冻结即时失效。浏览器测试走完整人工流程，并检查小屏溢出和退出清理。

本地服务运行时不下载外部字体或脚本。AI 状态明确为尚未接入，不用模板回答冒充推理。真实资料及真实批准程序在责任主体、相应模块和验收条件到位后才进入试用。

公共终端限制：退出会立即清除页面内存，刷新或新标签页要求显式登录。若退出时网络中断，服务端无法确认撤销；HttpOnly Cookie 和服务端会话仍可能在剩余闲置期限内有效，直接访问 API 不能仅靠页面清空来防护。界面会明确提示未确认注销。真实公共终端试用前，必须落实重连撤销、凭证隔离及现场退出验证；R0 不声称完整公共终端安全。

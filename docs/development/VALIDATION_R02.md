## 2. 权限、版本与模型结果的证据

私人候选及本人提供的三项语境只对作者开放；其他成员、主持人和管理员访问返回 404。分享候选后，议题响应只包含选定正文和必要版本信息，不包含原话、语境、用途或另一个候选。候选确认本身不建立分享。

听者只能针对自己当前有权读取的共享观点提交复述，不能给自己提交。理解请求和回应只对双方开放，作者才可核对；“需修正”必须填写修正。作者确认、纠正或要求当面交流均不改变议题立场和任务邀请状态。源撤回、版本或分享表示变化后，双方的后续读取与回应被阻断；同一当前有效版本重新分享后可读回既有记录，不伪造新回应。

改写原话、选定候选或改变选择使当前分享失效。幂等重放不重新执行分享，缓存议题响应重新过滤失效观点。历史收据可能仍返回成功响应；这不表示被撤下的内容重新生效。界面在本人修改后清除旧理解记录并重新读取当前列表，较早请求不能把已失效卡片填回来。其他人的页面须刷新才能取得最新视图；系统不能收回已经看到或保存的内容。

所有认证读取要求 Cookie 与登录时返回的页面内存证明。断网退出后，Cookie-only 读取 `/auth/me`、`/utterances`、`/topics`、`/audit` 均返回 401，不能取回证明；合法 Cookie 加证明可读取本人获准资料。刷新与新标签要求显式登录。服务端注销失败依然如实提示，不能声称会话已经撤销。

本地模型仅接受字面 loopback 地址，禁止环境代理、重定向、自动下载、云端回退和工具调用。协议测试包括无本机模型、错误地址／云类型配置、超限和恶意结构输出、十分钟来源证明的篡改／过期／跨人复用、繁忙及超时。

整个模型 HTTP 操作使用 `AsyncClient + asyncio.timeout` 的 60 秒截止时间，状态探测最多 3 秒；慢持续流、延迟响应头和慢探测均经可取消测试验证，超时释放并发门。该上限终止应用等待和连接，不保证 Ollama 服务内部的计算已经停止；页面最多约 65 秒接收结果，成员也可主动放弃等待。

等待推理时不持有 SQLite 写锁。事件门控并行测试实证：生成期间冻结账号返回 401，改写原话返回 409；私有模型正文不放行，也不自动创建候选。模型只收到当前原话及本人主动提供的语境，不读取历史私聊或其他业务对象。

## 4. 复跑命令

按根 README 安装依赖和构建，然后运行：

```bash
./scripts/check.sh
```

浏览器要求测试环境自行安装 Playwright 和 Chromium；口令使用至少 12 字符的合成测试值，绝不使用真实账号密码：

```bash
read -rs SYMSOIL_DEMO_PASSWORD
export SYMSOIL_DEMO_PASSWORD
export SYMSOIL_PLAYWRIGHT_MODULE=/tmp/symsoil-browser-qa/node_modules/playwright/index.mjs
.venv/bin/python tests/browser/run.py
SYMSOIL_BROWSER_SCRIPT=tests/browser/security.mjs .venv/bin/python tests/browser/run.py
SYMSOIL_BROWSER_SCRIPT=tests/browser/expressions.mjs .venv/bin/python tests/browser/run.py
SYMSOIL_BROWSER_SCRIPT=tests/browser/expressions.mjs SYMSOIL_TEST_AI_FIXTURE=1 \
  .venv/bin/python tests/browser/run.py
unset SYMSOIL_DEMO_PASSWORD
```

各运行启动自己的临时库和本机 API，结束后删除临时数据。不对现有社区实例运行 seed 或浏览器合成流程。设置 `SYMSOIL_TEST_ARTIFACTS` 可保存合成截图；原件、抽取全文、截图、数据库和模型权重均未提交 Git。

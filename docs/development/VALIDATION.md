## 已发现并处理

- 有条件支持省略条件时曾通过校验：默认值纳入校验，缺省或空白均拒绝。
- 退出后界面曾可凭 Cookie 自动恢复：改为每次刷新或新页显式登录，立即清除私人页面，注销期间禁用新登录，避免旧响应清除新 Cookie。
- 持续编辑曾只有前端活跃而服务器提前过期：最近有人操作时有限节奏续期，无人操作仍在五分钟退出。
- 表单长度、账号名 pattern、成员发起按钮和历史会话标记与后端不一致：已对齐，并进行了浏览器检查。
- 锁定的 Vite／Vitest 开发依赖曾有已知漏洞报告：更新修复版、重建锁文件并重新审计，报告漏洞归零；重新运行类型、测试和构建。

## 仍需完成

断网退出的真实限制已被独立浏览器实证：页面清空后，如果服务器没有收到注销，直接 API 请求仍可能凭剩余 Cookie 读取此前账号的数据。界面明确区分“页面已清除”和“服务器已确认退出”；本轮不声称完整公共终端安全。真实公共设备试用前必须补齐凭证隔离、重连撤销及现场验收。

未验收项目包括本地模型／RAG、正式批准、开始条件和执行授权、完整表达历史、共同记忆多人授权、导出与删除传播、管理员 MFA 及恢复、数据库迁移、备份恢复、全离线安装包、多浏览器可及性和真实社区接管。浏览器没有请求外域资源，并不等于已经完成物理断网及设备灾备演练。

后端测试出现 Starlette TestClient 对 httpx 的弃用提示；当前测试全部通过，后续依赖更新需连同测试客户端迁移。测试口令、数据库、截图和运行日志未提交到公开仓库。

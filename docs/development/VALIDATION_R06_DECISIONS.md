## 专项证据

| 场景 | 实际结果 |
| --- | --- |
| 立场与批准分离 | 已记录“支持”的立场不能使决定生效；只有名单内批准者可对精确决定版本批准 |
| 双人批准 | 第一名批准者完成后仍为待批准；第二名不同批准者完成后才可生效 |
| 条件与版本 | 未核实的生效条件阻止生效；提交冻结批准名单、规则版本和决定版本 |
| 资格撤销 | 撤销已用资格后，决定进入阻断状态、版本递增并清除旧批准；相同规则版本不可重新提交 |
| 账号冻结 | 最终批准前冻结既有批准者，决定失败关闭并清除旧批准 |
| 生效与开始分离 | 决定生效不自动开始；必需任务须由被邀请人本人接受，资源条件须独立核实 |
| 权限边界 | 普通成员不能登记批准资格；非议题主持人不能创建决定草稿 |
| 幂等 | 资格、提交、条件核实、批准和开始写入使用既有幂等机制，重复键返回既有结果 |

完整回归还覆盖表达准确性确认、分享、理解核对、立场、任务接受、资料审核、纠错与权限收紧恢复路径，证明这些合成流程仍保持独立，不证明真实协商质量或社区规则正当性。

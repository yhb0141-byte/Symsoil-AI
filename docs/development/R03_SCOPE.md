# R0.3 资料与来源增量

本轮继续 R0.2 的合成开发，在独立分支 `codex/r03-knowledge-library` 实现资料录入、审核、发布、查询与引用。合同见 [API_CONTRACT_R03.md](API_CONTRACT_R03.md)，当前进展见 [CONTINUATION.md](CONTINUATION.md)。该范围不等于完整 R1，也不构成社区试点签收。

| 能力 | 本轮目标 | 交付边界 |
| --- | --- | --- |
| 私人资料 | 文字／Markdown粘贴、必要来源、权利依据、用途、维护人、有效期及申请受众 | 私稿先保存在新版本表，不写公开快照；二进制上传、隔离解析、OCR后续实现 |
| 指定审核 | 明确授权另一位合格审核人读取本次精确版本，通过或说明退回 | 作者不能自审；管理员没有私人正文通读权；审核不是正式决定批准 |
| 版本发布 | 发布获准版本；新稿保留旧有效发布，改稿后重新送审 | 不静默替换正文或沿用旧审核；历史公开浏览及纠错工单后续实现 |
| 有限受众 | 社区当前成员或明确固定名单，作者可立即收紧／撤下 | 扩大受众需新版本重新审核；不能收回已被看到或另存的副本 |
| 目录与引用 | 当前权限下的关键词检索、有效期、来源卡、精确原文段落定位 | 使用小型本地关键词检索，不宣称向量／语义检索；未知旧资料隔离 |
| 资料问答 | 默认明确标记真实摘录；主动启用可选本地模型回答并列真实来源 | 无来源不回答业务事实；模型正文与引用分别校验，不自动发布；真实权重／中文质量未验收 |
| 数据库升级 | 增表，不改旧业务列；新seed初始化资料元数据，已知旧合成资料显式迁移 | 不自动批准未知历史行，不替真实社区选择维护人；生产迁移／恢复后续验收 |

验收需覆盖目录、标题、数量、正文、引用、模型输入和返回的同一权限边界，不能只测页面隐藏。生成途中冻结账号或撤下／取代／收紧来源必须阻止结果返回。源码完成、测试与浏览器通过后，在本轮验证记录填写实际证据；未执行项不能因接口合同存在而关闭。
